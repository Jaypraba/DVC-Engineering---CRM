# Content

Two collections, both plain MDX with typed frontmatter validated in
`lib/content.ts`. No CMS. Add a file, it appears; delete it, it goes.

- `projects/*.mdx` — case studies, surfaced at `/work` and `/work/[slug]`
- `journal/*.mdx` — writing, surfaced at `/journal` and `/journal/[slug]`

Set `published: false` to keep a file in the repo but off the site.

> **Everything currently in these folders is placeholder copy** written to
> exercise the layouts. Addresses, values and dates are invented. Replace each
> file with real project material before the site goes live.
